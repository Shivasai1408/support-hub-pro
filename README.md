# Support Hub Pro

Build a polished, production-style AI-powered customer support web app. Create a modern SaaS dashboard with a clean responsive UI using TypeScript, Tailwind CSS, and shadcn/ui. Include: (1) authentication screens, (2) support dashboard with KPIs for open tickets, response time, CSAT, and AI resolution rate, (3) ticket/inbox view with filters, priorities, statuses, customer details, conversation history, and assignment, (4) AI assistant panel that drafts replies, summarizes conversations, detects sentiment, suggests next actions, and can classify/route tickets, (5) customer profile view with ticket history, (6) knowledge base management for articles/FAQs that the AI can use, (7) analytics page with charts for ticket volume, resolution time, satisfaction, and AI automation, (8) settings page for team, notifications, AI behavior, and integrations. Seed the UI with realistic demo data and make the main workflows interactive. Use a professional customer-support visual style, excellent empty/loading/error states, accessible components, responsive layouts, and clear navigation. For AI features, implement convincing demo interactions/local mock behavior so the app works immediately, while structuring the code so a real AI API can be connected later. Use a dashboard shell with sidebar navigation and a top bar. Prioritize a polished MVP that feels like a real product.
